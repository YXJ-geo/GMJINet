# GMJINet

Research code for

> *Deep Learning for Joint Inversion of Gravity and Magnetic Data via Multiclass
> Pre-Training and Physics-Constrained Fine-Tuning*

## Status

This repository will host the implementation accompanying the manuscript above
(currently under review).

The release will include the network definitions, the supervised multiclass pre-training
and physics-constrained fine-tuning scripts, the prediction and evaluation scripts, the
MATLAB code used to generate the synthetic datasets, and the converged pre-trained
weights, together with documentation and a reproduction guide.

**It will be published here upon acceptance of the manuscript.** The repository URL is
permanent.

## Data and code availability

The synthetic datasets and the field survey data are not redistributable. The
synthetic datasets are generated by the MATLAB scripts included in the release; the
survey data were provided under terms that do not permit redistribution.
